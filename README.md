A Sudoku game for the Commodore 64, written in pure BASIC V2 (`sudoku.bas`).

## Features

- Random puzzle generation (band/stack shuffle method — no backtracking, fast on real hardware)
- Three difficulty levels: Easy (41 givens), Medium (31), Hard (23)
- Rotationally symmetric clue removal (classic newspaper-style pattern)
- Rule-based solution checking (validates rows/cols/3x3 boxes, not a fixed-answer compare)
- Cursor-based entry with a SID click on movement
- Black background, color-coded cells (white = given, yellow = entered, light red = active cell)

## Controls

| Key | Action |
|---|---|
| W/A/S/D or cursor keys | Move selection |
| 1-9 | Enter number |
| 0 | Clear cell |
| C | Check solution |
| R | Restart (clear entries, keep puzzle) |
| N | New puzzle (re-prompts difficulty) |
| Q | Quit |

## Building / Running

Convert the listing to a PRG with petcat (part of VICE):

```
petcat -w2 -o sudoku.prg -- sudoku.bas
```

Then run in VICE, or upload the PRG to a real C64 (e.g. via an Ultimate 64's REST API).

## Known limitations

- Clue removal is random, not solver-verified — puzzles are not guaranteed to have a unique solution.
- Requires an unmodified BASIC V2 environment (uses direct screen/color RAM POKEs and SID registers).
