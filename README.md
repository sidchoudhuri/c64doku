## [https://m0nde.itch.io/c64doku](https://m0nde.itch.io/c64doku)
A Sudoku game for the Commodore 64, written in pure BASIC V2 (`sudoku.bas`).

## Features

- Random puzzle generation (band/stack shuffle method — no backtracking, fast on real hardware)
- Three difficulty levels: Easy (41 givens), Medium (31), Hard (23)
- Rotationally symmetric clue removal (classic newspaper-style pattern)
- Rule-based solution checking (validates rows/cols/3x3 boxes, not a fixed-answer compare)
- Cursor-based entry with a SID click on movement
- Color-coded cells (white = given, yellow = entered, light red = active cell)
- Audio feedback for movement, number placement and row, column, square completion

## Controls

| Key | Action |
|---|---|
| W/A/S/D or cursor keys | Move selection |
| 1-9 | Enter number |
| 0 | Clear cell |
| C | Check solution |
| R | Restart (clear entries, keep puzzle) |
| N | New puzzle (re-prompts difficulty) |
| Q | Quit |

## Building / Running

- Look at c64doku.bas BASIC code in a text editor.
- Load the c64doku.prg file in VICE or on a real C64 or C64 Ultimate or Ultimate 64

## Known limitations

- Clue removal is random, not solver-verified
- Puzzles are not guaranteed to have a unique solution
